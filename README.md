# Jal_Jeevan_Mission
# Jal Jeevan Mission (JJM) – FHTC Coverage Analysis Dashboard

## 📌 Project Overview

This project analyzes **Jal Jeevan Mission (JJM)** data to monitor the progress of **Functional Household Tap Connections (FHTC)** across districts. The dashboard provides insights into scheme performance, water source distribution, district-wise coverage, and yearly trends.

The objective is to track the implementation of drinking water schemes and evaluate the percentage of households receiving tap water connections.

---

## 🎯 Objectives

* Monitor FHTC coverage across districts.
* Analyze the performance of water supply schemes.
* Compare Surface Water and Groundwater sources.
* Track yearly growth in household tap connections.
* Identify high and low-performing districts.
* Support data-driven decision-making for water resource management.

---

## 📂 Dataset Description

| Column Name         | Description                               |
| ------------------- | ----------------------------------------- |
| Year                | Reporting Year                            |
| Month               | Reporting Month                           |
| District            | District Name                             |
| Total_Schemes       | Total Water Supply Schemes                |
| SVS                 | Single Village Schemes                    |
| MVS                 | Multi Village Schemes                     |
| FHTC_Total          | Total Household Connections Targeted      |
| FHTC_Provided       | Household Connections Provided            |
| Percentage_Coverage | Coverage Percentage                       |
| Source_Type         | Water Source Type (Surface / Groundwater) |

## 📊 Dashboard Features

### KPI Cards

* **Total FHTC**

  * Total targeted household tap connections.
* **Provided FHTC**

  * Total completed household tap connections.
* **Coverage Percentage**

  * Overall achievement percentage.
* **Count of Areas**

  * Total districts/records analyzed.

### Visualizations

#### 1. Source Distribution

* Pie Chart
* Compares:

  * Surface Water
  * Groundwater

#### 2. District-wise Comparison

* Horizontal Bar Chart
* Shows FHTC provided by district.
* Helps identify top and bottom performing districts.

#### 3. Trend Over Time

* Line Chart
* Displays yearly growth in FHTC coverage.
* Includes trend line for performance tracking.

#### 4. Performance Analysis

* Column Chart
* Shows average percentage coverage across districts.

#### 5. District Filter (Slicer)

* Allows users to analyze specific districts.

---

## 📈 Key Metrics

### Coverage Formula

```text
Coverage % = (FHTC_Provided / FHTC_Total) × 100
```

### Scheme Classification

```text
Total Schemes = SVS + MVS
```

Where:

* SVS = Single Village Scheme
* MVS = Multi Village Scheme
